======================================================================
0. สถานะจริงของธีม (อ่านก่อนแก้)
======================================================================

CURRENT visual identity:
- Aesthetic: Premium corporate packaging — เขียวป่าเข้ม + ทองเหลือง/brass
- Mood: สุภาพ เชื่อถือได้ ไม่ดู marketplace ราคาถูก
- Mode: Light only ใน production UI
- Dark mode: PREPARED ใน CSS + Tailwind `dark:` หลายจุด แต่ยังไม่ทำงาน
- Theme toggle: มีไฟล์ ThemeToggle.tsx แต่ไม่มีที่ไหน import
- ThemeProvider: เป็น no-op (return children) เพื่อกัน hydration mismatch
- next-themes: ติดตั้งใน package.json แต่ ThemeProvider ไม่ได้ใช้
- Tailwind darkMode: ["class"] — ต้องใส่ class "dark" ที่ <html> จึงจะสลับ
- Semantic tokens (primary/accent/background): มีใน CSS แต่คอมโพเนนต์ไม่ใช้ bg-primary / text-primary

สองพื้นผิวหลักที่ใช้สีชุดเดียวกัน:
1. Storefront (ผู้ซื้อ) — Navbar paper โปร่ง, Hero forest เต็มจอ, Footer forest, CTA brass วงรี
2. Ops console (/ops) — header forest ทึบ, พื้นหน้า forest-mist/40, การ์ด paper, ปุ่ม forest (ไม่ใช่ brass)

2.3 Dark class ใน globals.css (.dark) — PREPARED ไม่ได้เปิด

--color-forest-mist    #1a332b     mist กลายเป็นเขียวเข้ม
--color-ink            #e8eee9     ตัวอักษรสว่าง
--color-paper          #10211b     paper กลายเป็นพื้นมืด
--background           #10211b
--foreground           #e8eee9
--card                 #163028
--muted                #1a332b
--border               rgba(255, 255, 255, 0.1)
--primary              #d9c08a     สลับเป็น brass-soft
--primary-foreground   #14352a

สิ่งที่ .dark ไม่ได้ override:
- --color-forest, --color-forest-light  ยังเขียวเข้ม — ถ้า Tailwind ชี้ CSS var จะ heading มืดบนพื้นมืด
- --color-brass, --color-brass-soft
- --accent, --ring

ดังนั้นแม้ใส่ class dark ที่ html ตอนนี้:
- คลาสที่ผูก semantic var (background/foreground) จะเปลี่ยน
- คลาส bg-forest / text-forest / text-ink / bg-paper ของ Tailwind ยังเป็น hex คงที่ จาก tailwind.config.ts
- คอมโพเนนต์ที่เขียน dark: เอง (Navbar, ProductCard) จะทำงานถ้ามี class dark
- หน้า ops ส่วนใหญ่ไม่มี dark: จะพัง contrast ถ้าเปิดมืดทั้งไซต์โดยไม่ปรับ

2.4 Tailwind config สีที่ map กับ CSS var (จะตาม :root/.dark)

background, foreground, card, muted, border, ring,
primary.DEFAULT, primary.foreground, accent.DEFAULT, accent.foreground

2.5 Tailwind config สีที่เป็น hex คงที่ (ไม่ตาม CSS var)

forest.DEFAULT / light / mist
brass.DEFAULT / soft
ink
paper

นี่คือเหตุผลหลักที่ “เปลี่ยนธีมที่ :root แล้วหน้าเว็บไม่เปลี่ยน”

3. Dual source of truth — ต้องรู้ก่อน retheme
======================================================================

ค่าเดียวกันถูกเขียนสองที่:

globals.css :root          tailwind.config.ts
#14352a --color-forest     forest.DEFAULT: "#14352A"
#1e4a3a --color-forest-light
#e9f0ea --color-forest-mist
#b08a3e --color-brass
#d9c08a --color-brass-soft
#22282c --color-ink
#ffffff --color-paper

Playbook เปลี่ยนสีแบรนด์ (เช่น เปลี่ยน forest เป็น navy):

ขั้นต่ำที่ต้องทำพร้อมกัน:
1. แก้ hex ใน tailwind.config.ts กลุ่ม forest/brass/ink/paper
2. แก้ hex ใน app/globals.css :root ทั้ง --color-* และ --background/--primary/--accent/--ring
3. แก้ .dark ให้สอดคล้อง (ถ้าจะเปิด dark)
4. แก้ radial-gradient ใน .bg-premium-mesh (rgba ของ brass 176,138,62 และ forest 20,53,42)
5. แก้ shadow ใน MobileStickyCta: rgba(20,53,42,0.08)
6. แก้ canvas ใน ProductMockupStudio.tsx ที่ fillStyle "#14352a" / "#1e4a3a"
7. แก้ lib/mockup-studio.ts preset forest/brass ถ้าต้องการให้ mockup ตามแบรนด์ใหม่
8. รัน lint + เปิดหน้า /, /products, /contact, /ops, พิมพ์เอกสาร, แคตตาล็อก

อย่าทำ:
- เปลี่ยนเฉพาะ CSS variable แล้วคาดหวัง bg-forest เปลี่ยน
- ใส่สีใหม่เป็น hex ตรงใน className ของหน้าใหม่ — ใช้ token เดิมหรือเพิ่ม token ใน config
- ใช้สี Tailwind default (emerald/sky/violet) กับ UI ผู้ซื้อ — ตอนนี้ใช้เฉพาะ ops SKU class badge

แนะนำถ้าจะ retheme จริงระยะยาว:
- ให้ forest/brass/ink/paper ใน Tailwind ชี้ var(--color-forest) ฯลฯ เหมือน primary
- เหลือ hex ที่เดียวใน :root / .dark
- ค่อยย้าย Button จาก bg-brass → bg-accent ถ้าต้องการ semantic layer

5. Contrast และคู่สีที่ต้องรักษา
======================================================================

คู่ที่ใช้บ่อย (ประเมินคร่าวสำหรับ AA):

พื้น #14352A forest + ตัวอักษร #FFFFFF paper     ผ่าน ตัวหนา/เนื้อหาบน footer, hero, ops header
พื้น #14352A + brass-soft #D9C08A                 ใช้ kicker/ชื่อแบรนด์ — ตรวจใหม่ถ้าเปลี่ยน brass
พื้น #B08A3E brass + ตัวอักษร #14352A forest      CTA หลัก — ต้องคง contrast เมื่อเปลี่ยนคู่ใดคู่หนึ่ง
พื้น #FFFFFF paper + #22282C ink                  เนื้อหาหลัก
พื้น #FFFFFF + #14352A forest                     heading
พื้น #E9F0EA mist + #14352A forest                badge, empty, ops canvas
พื้น brass แถบสาธิต + ตัวอักษร forest             ต้องอ่านได้บนมือถือ

กฎเมื่อ retheme:
- ตัวอักษรเนื้อหาบนพื้น ต้อง >= 4.5:1
- ตัวอักษรใหญ่/heading >= 3:1
- ห้ามใช้สีอย่างเดียวสื่อ error/success — ฟอร์มมี aria อยู่แล้ว
- อย่าใช้ #000000 หรือ #FFFFFF เป็น token ข้อความหลักถ้าไม่จำเป็น (ink ปัจจุบันไม่ใช่ดำบริสุทธิ์)
- ปุ่ม brass ถ้าทำให้สว่างขึ้น ตัวอักษร forest อาจตก AA — ปรับคู่กัน

8. Spatial grammar, มุมโค้ง, ความลึก
======================================================================

ความกว้าง:
- Storefront max-w-content = 72rem (1152px) จาก tailwind.config
- Ops max-w-6xl

มุมโค้ง token ใน Tailwind:
- sm  0.45rem
- md  0.65rem
- lg  0.9rem

ที่ใช้จริงบ่อยกว่า token ชื่อ:
- rounded-full   ปุ่มผู้ซื้อ, pill, หมายเลขขั้นตอน — นี่คือ signature ของ storefront
- rounded-2xl    การ์ดสินค้า, process step, บางแผง
- rounded-3xl    EmptyState
- rounded-xl     รูปใน ProductCard, การ์ด ops
- rounded        input ops, ปุ่ม ops บางตัว — มุมเหลี่ยมกว่าฝั่งขาย

ความลึก:
- Navbar / sticky CTA: backdrop-blur + พื้นโปร่ง
- ProductCard: shadow-sm → hover shadow-xl + translate-y-1
- Hero ภาพ: isolate + gradient ทับ
- ไม่มี elevation system เป็น token (ไม่มี --shadow-*)
