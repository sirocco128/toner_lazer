## 1. บทนำ

### 1.1 วัตถุประสงค์ของเอกสาร

อธิบายวิธีการใช้งานเว็บสาธารณะและ Ops Console ของระบบ Premium Gift Set สำหรับให้ผู้ใช้เข้าใจฟังก์ชัน ขั้นตอน และแนวทางแก้ปัญหาเบื้องต้น

### 1.2 ขอบเขตของระบบ

**ครอบคลุม:** Storefront, RFQ, ออเดอร์ลูกค้า (token), ชำระ PromptPay/สลิป, Ops CRM/ออเดอร์/โรงงาน/บัญชี/รายงาน, CMS Strapi  

**ไม่ครอบคลุม:** คู่มือ Strapi เชิงลึกทุก content-type, NextERP admin, การตั้งค่า Portainer เต็มรูปแบบ (ดู `docs/NAS-PORTAINER.md`)

### 1.3 กลุ่มผู้ใช้งานเป้าหมาย

| กลุ่ม | ช่องทาง |
|-------|---------|
| ลูกค้าจัดซื้อ | เว็บสาธารณะ + ลิงก์ออเดอร์/ชำระ |
| เซลล์ (sales) | `/ops` |
| บัญชี (accountant) | `/ops` โดยเฉพาะ approvals / finance |
| ผู้ดูแล (admin) | `/ops` ทั้งหมด + users |
| ผู้ดูอย่างเดียว (viewer) | `/ops` อ่านอย่างเดียว |
| บรรณาธิการ CMS | Strapi admin |

### 1.4 คำนิยามและคำย่อ

| คำ | ความหมาย |
|----|----------|
| RFQ | คำขอใบเสนอราคา (`quote_requests`) |
| Ops | คอนโซลพนักงาน `/ops` |
| Factory PO | ใบสั่งโรงงานจีน |
| SKU class A/B/C/D | สต็อก / สั่งผลิต / เคลียร์ / fill-in |
| Access token | โทเคนใน URL ให้ลูกค้าเปิดออเดอร์โดยไม่ login |

## 3. การเข้าสู่ระบบ (Login)

### 3.1 ลูกค้า (ไม่มี username)

1. รับลิงก์จากเซลล์ เช่น `/orders/{orderId}?t=…` หรือ `/pay/{voucherId}`
2. เปิดลิงก์บนเบราว์เซอร์ — โทเคนต้องถูกต้อง
3. <!-- placeholder: screenshot-customer-order -->

### 3.2 พนักงาน Ops

1. เปิด `https://{SITE}/ops/login` (local: `http://localhost:3000/ops/login`)
2. กรอกอีเมล/รหัสผ่าน **หรือ** Google Sign-In (อีเมลต้องมีใน staff แล้ว)
3. กดเข้าสู่ระบบ → Dashboard `/ops`
4. เซสชันคุกกี้ `ops_session` อายุ 12 ชั่วโมง
5. <!-- placeholder: screenshot-ops-login -->

### 3.3 การจัดการรหัสผ่าน

- Admin ตั้งรหัสผ่านใน `/ops/users` หรือ bootstrap จาก env (`ADMIN_*` / `OPS_USERS`)
- Google OAuth ไม่สร้างบัญชีใหม่อัตโนมัติ
- นโยบาย: รหัสผ่านพนักงานอย่างน้อย 12 ตัวอักษร (ตามเอกสาร Ops)

## 5. คู่มือการใช้งานแยกตามฟังก์ชัน (Feature Guide)

รูปแบบแต่ละหัวข้อ: **วัตถุประสงค์ → ขั้นตอน → ข้อควรระวัง**  
ตารางครบทุกหน้า: [05-FUNCTION-MATRIX.md](./05-FUNCTION-MATRIX.md)

### 5.1 หน้าแรก / เกี่ยวกับ / Landing

**วัตถุประสงค์:** แนะนำบริการและนำทางไปแคตตาล็อก/ติดต่อ  
**ขั้นตอน:** เปิด `/` หรือ `/about` หรือ `/premium-giftset` → เลือกหมวดหรือ CTA ขอใบเสนอราคา  
**ข้อควรระวัง:** ราคาที่แสดงเป็นช่วงโดยประมาณ ไม่ใช่ใบเสนอราคา

### 5.2 สินค้าและหมวดหมู่

**วัตถุประสงค์:** ค้นหา/เปรียบเทียบสินค้า พร้อมรายละเอียด MOQ ช่วงราคา สกรีน  
**ขั้นตอน:**
1. เปิด `/products` กรองหมวด
2. เปิด `/products/[slug]` ดูภาพ สเปค เพิ่มเข้าตะกร้าขอราคา
3. ใช้ mockup/360 ถ้าเปิดใช้ได้
4. กดไปแบบฟอร์ม RFQ ที่เติมสินค้าให้แล้ว

**ข้อควรระวัง:** ไม่ใช่ตะกร้าชำระเงิน

### 5.3 ไอเดีย / สั่งทำเซ็ต

**วัตถุประสงค์:** เลือกธีมหรือกำหนดเซ็ตเอง  
**ขั้นตอน:** `/ideas` → `[slug]` หรือ `/customize-gift-set` → ส่งรายละเอียดเข้า RFQ

### 5.4 ตะกร้าขอราคา (`/quote-basket`)

**วัตถุประสงค์:** รวมสินค้าที่จะขอราคา (เก็บในเบราว์เซอร์)  
**ขั้นตอน:** ปรับจำนวน → ส่งต่อไป `/contact`  
**ข้อควรระวัง:** ข้อมูลอยู่ในเครื่องผู้ใช้ ไม่ใช่ออเดอร์

### 5.5 แคตตาล็อก / อัลบั้ม

**วัตถุประสงค์:** เปิดแคตตาล็อกแบบพลิกหรืออัลบั้มที่เผยแพร่  
**ขั้นตอน:** `/catalog` หรือ `/album/[albumId]`

### 5.6 พอร์ตโฟลิโอ / บล็อก

**วัตถุประสงค์:** เคสและบทความ SEO  
**ขั้นตอน:** `/portfolio` `/blog` → เปิดรายละเอียดตาม slug

### 5.7 ติดต่อ / RFQ (`/contact`)

**วัตถุประสงค์:** ส่งคำขอใบเสนอราคาหรือข้อความทั่วไป  
**ขั้นตอน:**
1. กรอกบริษัท / ผู้ติดต่อ / สินค้า / จำนวน / งบ / จังหวัด
2. ใช้ค้นหาเลขผู้เสียภาษี (company lookup) ถ้ามี
3. ยินยอม PDPA → ส่ง
4. ได้รหัสคำขอทันที — **ยังไม่ต้องชำระเงิน**

**ข้อควรระวัง:** `?intent=message` สำหรับติดต่อทั่วไป/ร้องเรียน → ไปคิว `/ops/inquiries`

### 5.8 บัญชีลูกค้า / ออเดอร์

**วัตถุประสงค์:** ดูสถานะออเดอร์ เอกสาร ประวัติชำระ  
**ขั้นตอน:**
1. `/account` หรือ `/orders` ค้นหา
2. เปิดลิงก์ที่มี `?t=` จากเซลล์
3. ดูไทม์ไลน์ / ดาวน์โหลดเอกสาร / ไปชำระ

**ข้อควรระวัง:** ไม่มีรหัสผ่านลูกค้า — รักษาลิงก์เป็นความลับ

### 5.9 ชำระเงิน (`/pay/[voucherId]`)

**วัตถุประสงค์:** โอนตาม PromptPay QR และแนบสลิป  
**ขั้นตอน:** สแกน QR → โอน → อัปโหลดสลิป → รออนุมัติบัญชี  
**ข้อควรระวัง:** OCR ช่วยเทียบ แต่บัญชีเป็นผู้กดรับเงิน

### 5.10 แจ้งปัญหา (`/issues`)

**วัตถุประสงค์:** รายงานคุณภาพ/สกรีน/จำนวน/จัดส่ง  
**ขั้นตอน:** กรอกอ้างอิงออเดอร์ + รายละเอียด → ส่งเข้า `/ops/issues`  
**ข้อควรระวัง:** หน้านี้ไม่รับชำระเงิน

### 5.11 จองนัด (`/book/[slug]`)

**วัตถุประสงค์:** จองช่วงว่างของพนักงานตาม `booking_slug`  
**ขั้นตอน:** เลือกวันเวลา → ยืนยัน (อีเมลแจ้งถ้าตั้ง SMTP)

### 5.12 นโยบาย / ข้อกำหนด

อ่าน `/privacy` และ `/terms` ก่อนส่ง RFQ

### 5.13 Ops Board

**วัตถุประสงค์:** มองงานตามสถานะการ์ด  
**ขั้นตอน:** `/ops/board` — ดูกติกาที่ [../BOARD-STATUS-RULES.md](../BOARD-STATUS-RULES.md)

### 5.14 คำขอใบเสนอราคา (Quotes)

**วัตถุประสงค์:** ติดตาม RFQ เปลี่ยนสถานะ เปิดออเดอร์  
**ขั้นตอน:**
1. `/ops/quotes` กรองสถานะ
2. เปิดรายการ → บันทึกโน้ต / timeline
3. เมื่อลูกค้าตกลง → สร้างออเดอร์จากหน้า quote

สถานะ: ใหม่ → ติดต่อแล้ว → ส่งใบเสนอราคาแล้ว → ปิดการขาย / ไม่สำเร็จ → เก็บถาวร

### 5.15 Inquiries

**วัตถุประสงค์:** กล่องข้อความติดต่อ/ร้องเรียน  
**ขั้นตอน:** `/ops/inquiries` → อ่าน → เปลี่ยนสถานะ

### 5.16 ลูกค้า (CRM)

**วัตถุประสงค์:** บัตรภาษี รายชื่อติดต่อ LINE bind ประวัติ  
**ขั้นตอน:** ค้นหา `/ops/customers` → สร้างใหม่ / นำเข้า CSV / รวมลูกค้าซ้ำ / ส่งออก  
**ข้อควรระวัง:** merge ย้อนกลับยาก — ตรวจสอบก่อนรวม

### 5.17 ออเดอร์ Ops

**วัตถุประสงค์:** จัดการยอด มัดจำ fulfillment เอกสาร สร้าง PO  
**ขั้นตอน:** `/ops/orders/[orderId]` → ส่งลิงก์ลูกค้า → ติดตามสลิป → (admin) สร้าง factory PO หลังมัดจำ

### 5.18 ผู้ช่วยเซลล์ / LINE lab

**วัตถุประสงค์:** สรุปงาน ร่างข้อความ LINE ค้นแคตตาล็อก; ทดสอบ webhook  
**ขั้นตอน:** `/ops/assistant` · `/ops/line-lab`

### 5.19 ตารางนัด

**วัตถุประสงค์:** ปฏิทินเดือน/สัปดาห์/agenda + ชั่วโมงว่าง  
**ขั้นตอน:** `/ops/schedule` สร้าง/แก้/ยกเลิก/ส่งแจ้งเตือน · ตั้ง availability

### 5.20 ราคา / import

**วัตถุประสงค์:** คิด landed cost / ราคาขาย · อัปเดตจาก Excel  
**ขั้นตอน:** `/ops/pricing` → preview → apply · ดู config ที่บันทึก

### 5.21 สินค้า / SKU master

**วัตถุประสงค์:** จัดการ ORI, SKU A/B/C/D, สี, กลุ่ม, bundle, serial  
**ขั้นตอน:** `/ops/products` … ตามเมนูย่อย · ย้ายของเสียไป class C ตาม SOP

### 5.22 แคตตาล็อกภายใน / รูป 1688

**วัตถุประสงค์:** สร้างอัลบั้ม · ค้นหารูปโรงงานผ่าน Gemini เก็บในระบบ  
**ข้อควรระวัง:** รูปแหล่งภายใน ≠ แคตตาล็อกสาธารณะโดยอัตโนมัติ

### 5.23–5.29 โรงงาน / รับเข้า / คลัง / จ่าย / สินทรัพย์ / เคลม / Hold

| เมนู | URL | สรุปขั้นตอน |
|------|-----|-------------|
| โรงงาน | `/ops/factories` | ทะเบียนโรงงาน เงื่อนไข สกุลเงิน |
| ใบสั่ง | `/ops/factory-po` | ร่าง→ส่ง→ยืนยัน→ผลิต→ขนส่ง→รับ (หลังมัดจำเท่านั้น) |
| รับเข้า | `/ops/inbound` | บันทึกจำนวน เสีย ขาด QC · **บังคับ product key** เมื่อเข้าคลัง · ยกเลิกใบรับได้ถ้ายังไม่จ่ายเกิน |
| คงเหลือคลัง | `/ops/stock` | ดู on-hand / reserved / available ตาม SKU+ที่เก็บ · แดชบอร์ดค้างรับ |
| เคลื่อนไหว | `/ops/stock/movements` | ประวัติรับ จอง ตัด ส่ง ปรับ โอน |
| ปรับ/โอน | `/ops/stock/adjust` | ปรับยอด หรือโอนระหว่าง BIN-DEFAULT ↔ BIN-QC |
| ตรวจนับ | `/ops/stock/counts` | นับจริง → variance → ปรับอัตโนมัติ |
| จ่ายโรงงาน | `/ops/pay-factory` | จ่ายไม่เกินยอดที่รับ |
| สินทรัพย์ | `/ops/assets` | ล็อตคลัง (คู่กับใบรับ) |
| เคลม/ปัญหา | `/ops/claims` `/ops/issues` | ติดตาม |
| Legal hold | `/ops/holds` | hold/release สองคน (เอกสาร — ไม่ใช่ QC quarantine) |

**กติคาสต็อก:** `qty_on_hand ≥ 0`, `qty_reserved ≤ qty_on_hand`, available = on_hand − reserved · จองตอนรับเข้าออเดอร์ · ตัดตอนส่ง · ของเสียเข้า QC แยกจากพร้อมขาย

รายละเอียด sequence: [03-WORKFLOWS.md](./03-WORKFLOWS.md) · [SOP-CYCLE.md](../SOP-CYCLE.md)

### 5.30 อนุมัติสลิป

**วัตถุประสงค์:** บัญชีตรวจสลิปออเดอร์/ใบรับเงิน  
**ขั้นตอน:** `/ops/approvals` → เปิดรายการ → อนุมัติหรือปฏิเสธพร้อมเหตุผล

### 5.31 ใบรับเงิน / QR

**วัตถุประสงค์:** สร้างใบรับเงินรายการย่อยและ PromptPay QR  
**ขั้นตอน:** `/ops/receipts` · `/ops/qr-pay`

### 5.32 ศูนย์วงจร (`/ops/cycle`)

**วัตถุประสงค์:** รวมลิงก์ฟอร์มทั้งวงจรปฏิบัติการในหน้าเดียว

### 5.33 บล็อก / SEO

**วัตถุประสงค์:** ร่างบทความ (มือ/AI) ผ่าน draft→review→live→archive · แก้ SEO รายหน้า

### 5.34 Audit

### 5.35 ผู้ใช้ / RBAC

## 7. การแก้ไขปัญหาเบื้องต้นและ FAQ

### 7.1 ข้อผิดพลาดที่พบบ่อย

| ข้อความ/อาการ | สาเหตุ | วิธีแก้ |
|---------------|--------|---------|
| เข้า `/ops` แล้ว forbidden | ไม่มีสิทธิ์เมนู | ติดต่อ admin ปรับ grants |
| ลิงก์ออเดอร์เปิดไม่ได้ | token ผิด/หมดอายุ | ขอลิงก์ใหม่จากเซลล์ |
| สลิปไม่ผ่าน | ยอด/บัญชีไม่ตรง | โอนใหม่ตาม QR แล้วอัปโหลดใหม่ |
| สั่งผลิตไม่ได้ | ยังไม่มัดจำ | รออนุมัติสลิปมัดจำ |
| Error 401 | เซสชันหมด | login ใหม่ |
| Error 500 | ระบบขัดข้อง | ลองใหม่ / ติดต่อ support |

### 7.2 FAQ

**ถาม:** ทำไมกดซื้อแล้วไม่ตัดบัตร?  
**ตอบ:** ระบบไม่ใช่ e-commerce ชำระทันที — ต้อง RFQ แล้วเซลล์เปิดออเดอร์

**ถาม:** ราคาบนเว็บใช้สั่งผลิตได้เลยหรือไม่?  
**ตอบ:** ไม่ได้ เป็นช่วงโดยประมาณ

**ถาม:** เซลล์เห็นต้นทุนโรงงานหรือไม่?  
**ตอบ:** ไม่ — เฉพาะ admin (และสิทธิ์ที่ให้เพิ่ม)
