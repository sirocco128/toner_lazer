## คำขอตัดสินใจ (อ่านตอนปิด)

1. รับรอง `/ops/manual` เป็นช่องทางคู่มือปฏิบัติการหลัก  
2. แต่งตั้งเจ้าของเอกสารรายฝ่าย  
3. คงนโยบายเอกสาร deploy/infra เฉพาะ admin  
4. นัดอบรมสั้นเซลล์/บัญชีภายใน 2 สัปดาห์  

---

## วิธีนำเสนอ

1. เปิดไฟล์ HTML ในเบราว์เซอร์ (Chrome/Edge)  
2. กดลูกศรซ้าย/ขวา หรือปุ่มด้านล่าง · `Space` = ถัดไป  
3. กด **พิมพ์ / PDF** เพื่อส่งเป็น PDF ให้ผู้บริหาร  
4. สาธิตสดคู่กับ `http://localhost:3001/ops/manual` (หรือโดเมนโปรดักชัน)
